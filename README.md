# 🐾 냥냥 브릭

귀여운 고양이 발판으로 젤리 벽돌을 깨는 브라우저 게임입니다. 설치 없이 PC와 모바일에서 플레이할 수 있습니다.

- 마우스, 방향키, A/D 또는 터치: 이동
- 클릭, 터치 또는 Space: 발사
- P: 일시정지 / 이어하기
- 5개 스테이지, 목숨 3개, 브라우저에 최고 기록 저장
- 효과음은 소리 버튼으로 켤 수 있습니다.

`index.html`을 브라우저에서 열면 실행됩니다. 외부 라이브러리 없이 HTML, CSS, Canvas JavaScript로 구현했습니다. Google Fonts 연결이 없어도 시스템 글꼴로 실행됩니다.
